## 二、设计规范与 Design Tokens 体系

全套 12 页面统一贯彻**玄墨夜空深色科技规范 (Dark Tech-Chinoiserie)**，将东方水墨意境、天圆地方哲学与未来赛博科技精密控件融合：

### 1. 颜色体系 (Color Palette Tokens)
* **画布与背景基底**：
  * 主背景底色：`#0A0F1D` / `#0B0F19`（玄墨深空）
  * 容器中层底色：`#0F172A` / `#131C31`（沉檀蓝墨）
  * 悬浮/卡片高层：`#182238` / `#1E293B`（群青墨石）
  * 边框描边（1px）：`rgba(37, 99, 235, 0.18)` 到 `rgba(255, 255, 255, 0.08)`（微光青霜）
* **品牌与主视觉色调**：
  * 科技主色（Primary）：`#2563EB`（科技群青 / Ultramarine Blue）
  * 亮色强调（Accent Cyan）：`#06B6D4` / `#38BDF8`（天水碧 / Cyber Cyan）
  * 成功与放行（Success / Gate）：`#10B981` / `#0D9488`（琅琊翡翠）
  * 警告与伏笔（Warning / Clue）：`#F59E0B` / `#D97706`（赤金琥珀）
  * 危险与驳回（Destructive / Danger）：`#EF4444` / `#DC2626`（朱砂丹红）
* **文本阶度 (Typography Colors)**：
  * 主标题/高亮字：`#F8FAFC`（宣纸白，100% 不透明）
  * 正文与核心读数：`#E2E8F0` / `#CBD5E1`（云雾银，85% 不透明）
  * 次要说明/元数据：`#94A3B8`（淡墨灰，65% 不透明）
  * 占位符与微弱提示：`#64748B`（烟灰，40% 不透明）

### 2. 字体与排印规则 (Typography & Scale)
* **西文与数值**：`Inter`, `-apple-system`, `system-ui`, 等宽字体 `JetBrains Mono`（用于版本哈希、词频、行号）。
* **中文与正文**：`PingFang SC`, `Noto Serif SC`（宋体/仿宋韵致，用于章节正文、小说诗句与宣发金句）。
* **字号梯度**：
  * Page Title: 20px / 24px (Bold, Tracking -0.02em)
  * Section Header: 14px / 16px (Semi-Bold)
  * Body Text: 13px / 14px (Line-height 1.6)
  * Metadata / Badge / Tag: 11px / 12px (Regular & Medium)

### 3. 圆角与阴影规范 (Radii & Elevation)
* **圆角**：
  * 胶囊/标签/按钮：`rounded-full` 或 `rounded-lg (8px)`
  * 卡片与弹窗视窗：`rounded-xl (12px)` 或 `rounded-2xl (16px)`
* **阴影与光晕 (Glows)**：
  * 常规卡片阴影：`0 10px 25px -5px rgba(0, 0, 0, 0.5)`
  * 霓虹微光环绕：`box-shadow: 0 0 20px -3px rgba(37, 99, 235, 0.35)`
  * 翡翠成功光晕：`box-shadow: 0 0 25px -2px rgba(16, 185, 129, 0.4)`

## 三、全局公共组件与 Shell 交互协议

全套系统共享顶层应用壳（App Shell），包含两大常驻交互区：

### 1. 顶部全局航标栏 (Top Navigation Bar)
* **左侧品牌标识**：墨滴芯片 Logo + `FCS Studio · TECH-CHINOISERIE 墨境`。
* **书卷上下文选择器 (Breadcrumb & Project Switcher)**：
  * 点击唤起《星海之约》等项目的极速切换浮层；
  * 显示当前处于的子模块（如：`6. 版本管理 · Version Control`）。
* **全局实体指令面板 (Command Bar · `⌘K`)**：
  * 支持输入任意提交 ID、角色名字（苏明月/林陌）、法宝、伏笔编号或分支名称进行毫秒级全文索引与跳转。
* **算力指示器与创作者信息**：
  * **AI 算力点**：`14,250`（带闪电微光动画）；
  * **通知气泡**：红点提醒待批注与协作者提交；
  * **主快捷动作**：高亮群青色 `+ 创建新分支 / 提交版本` 按钮；
  * **用户头像**：任舟（创作者 · 灵感涌现中）。

### 2. 左侧持久导航中枢 (Persistent Left Sidebar)
* **工作台 (Dashboard)**：高亮激活状态 `ACTIVE` 绿标，映射 Page 01。
* **项目 (Projects)**：显示数量徽标 `12`，映射项目库大厅。
* **成果库 (Artifacts)**：沉浸成果展示。
* **插件中心 (Plugins)**：显示 `4已启用`，映射 Page 09。
* **系统设置 (Settings)**：映射 Page 10。
* **底部折叠面板**：创作者任舟状态切换器（可切免打扰/离线/构思态）。

## 四、12 页面全息交互流转矩阵与功能详述

### 页面 1：工作台总览 · Dashboard
* **页面定位**：创作者日常启动页、创作进展看板与灵感发射台。
* **核心模块**：
  * 欢迎横幅大看板：“你好，创作者！今天想创作什么呢？[开始新项目]”；
  * 灵感画卷与近期项目矩阵（《星海之约》、《永恒之塔》、《迷雾之城》）；
  * 快捷入口网络（AI创作助手、Novel Graph、版本管理、团队协作）；
  * 今日创作字数、热力时钟与灵感碎片收纳盒。
* **交互流转入口**：
  * 点击项目卡片《星海之约》➔ 进入【页面 2：Novel Graph】或【页面 4：章节编辑器】；
  * 点击“AI 创作助手”快捷卡 ➔ 进入【页面 3：AI 创作助手】；
  * 点击“开始新项目” ➔ 呼出项目创建向导。

---

### 页面 2：Novel Graph · 叙事图谱
* **页面定位**：全书核心事实源（Single Source of Truth），空间几何化掌控人物、因果、伏笔与世界观。
* **核心模块**：
  * **中间无限画布**：节点聚类（主线剧情、关键事件、主要角色苏明月/林陌、世界设定）、高阶贝塞尔因果连线与力导向物理引擎；
  * **顶部图谱控制器**：缩放比例 (100%)、布局算法切换（分层/同心圆/力导向）、全景小地图、历史版本快照；
  * **右侧实体全息详情面板 (Inspector)**：
    * 角色属性卡（苏明月：主线核心、20岁、宗门巡天卫）；
    * 伏笔状态与人际羁绊网络（关联事件12、出场章节6）；
    * 一键触发“图谱一致性校验”与“因果链推演”。
* **交互流转入口**：
  * 双击任意剧情节点 ➔ 直接跳转至【页面 4：章节编辑器】对应段落；
  * 点击右侧“AI 校验因果” ➔ 唤醒【页面 3：AI 创作助手】带上下文对话；
  * 底部 Tab 切换至“时间线视图” ➔ 跳转【页面 5：时空时间线】。

---

### 页面 3：AI 创作助手 · 智能协作
* **页面定位**：AI 智囊群多模态协同工坊，深度挂载当前章节与图谱实体。
* **核心模块**：
  * **左侧创作技能菜单**：灵感激发、情节生成、角色塑造、世界构建、文本润色、大纲优化；
  * **对话视窗主界面**：
    * 智能助手机器人问候：“我是你的创作助手，有什么可以帮助你？”；
    * 快捷预设提示胶囊（“扩展这个情节的可能性”、“检阅角色行为一致性”、“生成下一个章节大纲”）；
    * 正文协同片段预览（展示《第一章 迷雾之城》AI 推演的生成段落与微调色板）；
  * **底部智能输入框**：支持 `@` 呼出图谱角色与设定词条。
* **交互流转入口**：
  * 点击生成片段右下角“加入大纲” ➔ 自动同步并插入【页面 2：Novel Graph】；
  * 点击“采纳并插入正文” ➔ 自动注入【页面 4：章节编辑器】当前光标处。

---

### 页面 4：章节编辑器 · Editor
* **页面定位**：工业级沉浸生产车间，结构化大纲与正文双向联动。
* **核心模块**：
  * **左侧卷章目录树**：第1卷《追溯》、第1章《迷雾之城》、第2章至第5章折叠列表，支持拖拽重排与状态标记；
  * **顶部排版工具栏**：粗体、斜体、引用、对白提取、诗词排版、全屏禅意模式（Zen Mode）；
  * **中间沉浸正文编辑区**：
    * 对白与叙述自动高亮；
    * 正文插图透视渲染（苏明月站在高楼之巅俯瞰万家灯火）；
    * 划词唤醒悬浮 AI 润色气泡；
  * **字数与气韵底座**：本章 3,240 字，全书阅读耗时估算，情绪张力实时微缩折线。
* **交互流转入口**：
  * 点击行间关联的角色名/法宝（带点状下划线） ➔ 侧边划出【页面 11：数据管理】资产卡；
  * 完成章节修改后点击“提交保存” ➔ 弹出【页面 6：版本管理】差异提交抽屉。

---

### 页面 5：时空时间线 · Timeline
* **页面定位**：多角色时空轨迹、因果因缘与多维视界校验器。
* **核心模块**：
  * **视图维度切换**：事件线图 (Event Chart)、时间视图 (Chronological)、关系视图 (Relationships)；
  * **横轴绝对时间尺度**：星海历 942 年春至 944 年秋（标记第 1 章至第 20 章）；
  * **纵向轨道矩阵**：
    * 角色主线轨道（苏明月·巡天轨迹、林陌·阵修行动）；
    * 阵营冲突轨道（重霄城护防司 vs 绝息矩阵）；
    * 伏笔触发点与重要历史事件里程碑条带。
* **交互流转入口**：
  * 点击时间轴上的“时间悖论警戒标记” ➔ 联动进入【页面 8：审核与门禁】查看时空校验报告；
  * 点击事件节点 ➔ 联动定位【页面 2：Novel Graph】。

---

### 页面 6：版本管理 · Version Control
* **页面定位**：创作生命线，支持像 Git 一样管理长篇巨著的演进、回溯与分支。
* **核心模块**：
  * **左侧版本历史树 (Commit History)**：
    * `v1.0.0` (完整终卷正式版)、`v0.9.8` (优化剧情逻辑)、`v0.9.7` (调整角色设定) 等可视化节点与作者签名；
  * **右侧分屏差异对比 (Split-Screen Diff)**：
    * 【对比视图】：红删绿增对比修改前后字句；
    * 【文件变更】：展示图谱节点增减、正文字数变动（`+1,420 / -280` 字）；
  * **底部动作条**：恢复此版本、合并分支、创建新快照。
* **交互流转入口**：
  * 点击“创建正式发版” ➔ 触发进入【页面 8：审核与质量门禁】；
  * 点击“回溯节点” ➔ 恢复全站数据至该时刻。

---

### 页面 7：多人协作 · Collaboration
* **页面定位**：团队多人实时共创、主编终审与任务看板。
* **核心模块**：
  * **左侧项目成员列表**：星晨（制作人/管理员）、墨白（主笔编剧）、清风徐来（设定统筹）、未来可期（特邀终校）等在线状态与角色权限胶囊；
  * **中间讨论与批注留言流**：
    * 关联章节定位的批注对话（“第12章这段节奏可以更紧凑一些”）；
    * 表情互动与快捷 `@` 指向；
  * **右侧协同任务看板 (Task Board)**：
    * 进行中 (3)：优化角色设定、检查时间线逻辑、润色文案风骨；
    * 已完成事项打勾归档。
* **交互流转入口**：
  * 点击任务条目 ➔ 跳转至【页面 4：章节编辑器】对应批注行；
  * 点击“邀请新成员” ➔ 打开【页面 10：项目设置】权限配置页。

### 页面 8：审核与质量门禁 · Review & Gate
* **页面定位**：工业化出版级质检放行中枢，确保无时空断裂与战力崩塌。
* **核心模块**：
  * **顶部发版状态横幅**：`Gate Passed 审核通过 (RELEASE READY)`，包含 4 大核心指标：
    * 叙事连贯性：`98.6%`
    * 逻辑一致性：`0 悖论`
    * 合规检测：`100%`
    * 综合质量评分：`92 / 100` (卓越 S 级)；
  * **左侧六维雷达图与合规审核**：自洽度 96、人物纯度 91、伏笔回收 89、节奏呼吸感 93、文风雅致 95；
  * **右侧门禁校验细则清单**：时空悖论检验 [PASS]、角色存活状态自洽 [PASS]、伏笔回收预警 [建议关注]、人物对白口吻微调建议；
  * **底部多方联合签署流水线**：编剧、设定统筹、资深审读与 AI Gatekeeper 联合签字盖章。
* **交互流转入口**：
  * 点击高亮按钮“批准并发布正式版 (Sign-off)” ➔ 自动结转至【页面 12：发布与分发】；
  * 点击对白润色建议“一键替换为「胜算」” ➔ 自动回写至【页面 4：章节编辑器】。

* **页面定位**：项目宏观全局规则、视角约束、封面装帧与安全合规防线。

## 六、研发对接与状态机说明 (Developer Handoff & State Machine)

### 1. 核心状态机设计 (State Management)
* **Novel Graph 实体状态**：
  * `DRAFT` (草稿灵感) ➔ `CANONICAL` (正史事实源，受主编锁保护) ➔ `DEPRECATED` (历史分支废弃)。
* **章节发布状态**：
  * `WRITING` (撰写中) ➔ `IN_REVIEW` (协作审核中) ➔ `GATE_PASSED` (门禁放行) ➔ `PUBLISHED` (已全渠道分发)。
* **质检门禁规则判定**：
  * 阻断级错误 (Blocker, 出现时禁止签署) = 时空悖论 > 0 OR 敏感词违规 > 0 OR 关键角色死亡因果倒置；
  * 建议级告警 (Warning, 允许签字放行) = 伏笔长周期未呼应 OR 现代口语词轻度超标。

### 2. 响应式布局断点规范
* **Desktop (默认交付标准)**：`min-width: 1440px`，三栏/两栏弹性吸附；
* **左侧 Sidebar**：默认宽 `240px`，支持一键折叠为 `64px` 图标抽屉；
* **右侧 Inspector Drawer**：固定宽 `380px` ~ `420px`，支持平滑滑入与蒙层覆盖。
